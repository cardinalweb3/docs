The SafeSend contract locks ERC-20 tokens at the time of creation and holds them until a future release time chosen by the sender. During the window between creation and that release time, the sender can cancel and recover their tokens in full. After the release time, anyone can trigger settlement — the recipient receives the transfer amount minus the platform fee, and the fee goes to the configured fee recipient. This design gives senders a meaningful cancellation window without requiring the recipient's cooperation to complete eventual settlement.

<Warning>
  The SafeSend contract is deployed on **Arbitrum Sepolia testnet only**. It has not been externally audited and is not approved for mainnet use. Use it exclusively with testnet funds.
</Warning>

## Transfer statuses

A SafeSend transfer moves through the following states. Terminal states (`Cancelled`, `Released`) cannot be processed again.

| Status      | Value | Meaning                                                    |
| ----------- | :---: | ---------------------------------------------------------- |
| `None`      |   0   | No transfer exists for this ID                             |
| `Pending`   |   1   | Tokens are locked; release time has not been reached       |
| `Cancelled` |   2   | Sender cancelled; full amount returned to sender           |
| `Released`  |   3   | Recipient and fee recipient were paid after release time   |

## Functions

### createSafeSend

```solidity
function createSafeSend(
    address recipient,
    address token,
    uint256 amount,
    uint256 releaseTime
) external returns (uint256 transferId)
```

Creates a new protected transfer and immediately pulls the full `amount` from your wallet into the contract. The fee is calculated at creation time and stored with the transfer record; it is deducted from the locked amount when the transfer is released, not when it is created.

**Caller:** Sender (you must have approved the contract to spend at least `amount` tokens first)

<ParamField path="recipient" type="address" required>
  Wallet address that will receive tokens after the release time. Must be non-zero.
</ParamField>

<ParamField path="token" type="address" required>
  ERC-20 token contract address. Must be non-zero. Only ERC-20 tokens are supported.
</ParamField>

<ParamField path="amount" type="uint256" required>
  Total token amount to lock. Must be greater than zero. The full amount is transferred from your wallet immediately; the platform fee is deducted from this amount at release time.
</ParamField>

<ParamField path="releaseTime" type="uint256" required>
  Unix timestamp (in seconds) after which the transfer becomes releasable. Must be strictly greater than the current block timestamp.
</ParamField>

**Returns:** `transferId` — a `uint256` that uniquely identifies this transfer. Store it to cancel or release the transfer later.

**Emits:** `SafeSendCreated`

<Note>
  Before calling `createSafeSend`, call `previewFee(amount)` to show the user the exact fee that will be deducted on release. Approve only the exact transfer amount — do not request an unlimited approval.
</Note>

### cancelSafeSend

```solidity
function cancelSafeSend(uint256 transferId) external
```

Cancels a pending transfer before the release time and returns the full locked amount to the original sender. No fee is charged on cancellation.

**Caller:** Original sender only

<ParamField path="transferId" type="uint256" required>
  ID of the transfer to cancel. The transfer must be in `Pending` status and the current block timestamp must be earlier than `releaseTime`.
</ParamField>

**Emits:** `SafeSendCancelled`

<Warning>
  Cancellation is impossible at or after `releaseTime`. Always show the on-chain release time to the sender rather than relying on a local countdown timer, since block timestamps and local clocks can diverge.
</Warning>

---

### releaseSafeSend

```solidity
function releaseSafeSend(uint256 transferId) external
```

Delivers tokens to the recipient and transfers the platform fee to the fee recipient. Anyone may call this function once the release time has been reached — the caller does not need to be the sender or recipient. This enables settlement automation without granting the automation service any control over destination or amount.

**Caller:** Anyone (permissionless after `releaseTime`)

<ParamField path="transferId" type="uint256" required>
  ID of the transfer to release. The transfer must be in `Pending` status and `block.timestamp` must be greater than or equal to `releaseTime`.
</ParamField>

**Emits:** `SafeSendReleased`

---

### getSafeSend

```solidity
function getSafeSend(uint256 transferId) external view returns (SafeSendTransfer memory)
```

Returns the full on-chain record for a transfer. Use this as the source of truth for transfer status, fee, and timing — do not rely on local state or event logs alone.

**Caller:** Anyone (view function, no gas cost)

<ParamField path="transferId" type="uint256" required>
  ID of the transfer to read.
</ParamField>

**Returns:** A `SafeSendTransfer` struct with the following fields:

| Field         | Type              | Description                                              |
| ------------- | ----------------- | -------------------------------------------------------- |
| `sender`      | `address`         | Wallet that created and funded the transfer              |
| `recipient`   | `address`         | Wallet that receives funds after release                 |
| `token`       | `address`         | ERC-20 token held by the contract                        |
| `amount`      | `uint256`         | Total token amount locked                                |
| `feeAmount`   | `uint256`         | Platform fee recorded at creation time                   |
| `releaseTime` | `uint256`         | Unix timestamp when release becomes available            |
| `status`      | `SafeSendStatus`  | Current transfer state (see transfer statuses above)     |

---

### previewFee

```solidity
function previewFee(uint256 amount) external view returns (uint256 feeAmount)
```

Returns the platform fee that would be charged for a given transfer amount. Call this before creating a transfer to show the user what they will actually pay.

**Caller:** Anyone (view function, no gas cost)

<ParamField path="amount" type="uint256" required>
  The total token amount you plan to lock in the transfer.
</ParamField>

**Returns:** `feeAmount` — the token amount that will be deducted from the locked balance on release.

**Fee formula:**

```
feeAmount = amount × feeBps ÷ 10,000
```

The current pilot fee is **2.5% (250 basis points)**. For example, a 1,000 USDC transfer produces a fee of 25 USDC, and the recipient receives 975 USDC.

## Events

| Event               | Parameters                                                                   | When emitted              |
| ------------------- | ---------------------------------------------------------------------------- | ------------------------- |
| `SafeSendCreated`   | `transferId`, `sender`, `recipient`, `token`, `amount`, `feeAmount`, `releaseTime` | Transfer created and funded |
| `SafeSendCancelled` | `transferId`, `sender`                                                       | Transfer cancelled by sender |
| `SafeSendReleased`  | `transferId`, `recipient`, `recipientAmount`, `feeAmount`                    | Tokens delivered to recipient |
| `FeeConfigUpdated`  | `feeRecipient`, `feeBps`                                                     | Fee configuration changed  |
| `OwnershipTransferred` | `previousAdmin`, `newAdmin`                                               | Administrative ownership transferred to a new admin |

## Ethers.js example

The example below shows the complete interaction sequence: approve tokens, preview the fee, create a SafeSend with a one-hour release window, and wait for confirmation.

```typescript
import { ethers } from 'ethers';

const SAFESEND_ABI = [
  'function createSafeSend(address recipient, address token, uint256 amount, uint256 releaseTime) returns (uint256)',
  'function cancelSafeSend(uint256 transferId)',
  'function releaseSafeSend(uint256 transferId)',
  'function getSafeSend(uint256 transferId) view returns (tuple(address sender, address recipient, address token, uint256 amount, uint256 feeAmount, uint256 releaseTime, uint8 status))',
  'function previewFee(uint256 amount) view returns (uint256)',
];

const ERC20_ABI = [
  'function approve(address spender, uint256 amount) returns (bool)',
  'function allowance(address owner, address spender) view returns (uint256)',
];

const SAFESEND_ADDRESS = '0xC2b58B0CB938d35836E5a4E34b79Bd5E8EcD8f78';
const TEST_USDC_ADDRESS = '0x15EA32f1eF5c28225E3c9FFbd7741785Cff752d0';

const provider = new ethers.BrowserProvider(window.ethereum);
const signer = await provider.getSigner();

const safeSend = new ethers.Contract(SAFESEND_ADDRESS, SAFESEND_ABI, signer);
const usdc = new ethers.Contract(TEST_USDC_ADDRESS, ERC20_ABI, signer);

const amount = ethers.parseUnits('1000', 6); // 1,000 USDC (6 decimals)

// Preview the fee before showing the user a confirmation UI
const fee = await safeSend.previewFee(amount);
console.log('Platform fee:', ethers.formatUnits(fee, 6), 'USDC');
console.log('Recipient receives:', ethers.formatUnits(amount - fee, 6), 'USDC');

// Approve the exact amount (never request unlimited approval)
const currentAllowance = await usdc.allowance(await signer.getAddress(), SAFESEND_ADDRESS);
if (currentAllowance < amount) {
  const approveTx = await usdc.approve(SAFESEND_ADDRESS, amount);
  await approveTx.wait();
}

// Create a SafeSend with a 1-hour release window
const releaseTime = Math.floor(Date.now() / 1000) + 3600;
const recipientAddress = '0xRecipientAddress';

const tx = await safeSend.createSafeSend(
  recipientAddress,
  TEST_USDC_ADDRESS,
  amount,
  releaseTime
);
const receipt = await tx.wait();

// Extract the transferId from the SafeSendCreated event
const event = receipt.logs
  .map((log) => {
    try { return safeSend.interface.parseLog(log); } catch { return null; }
  })
  .find((e) => e?.name === 'SafeSendCreated');

const transferId = event?.args.transferId;
console.log('Transfer created with ID:', transferId.toString());

// Read the transfer back to confirm on-chain state
const transfer = await safeSend.getSafeSend(transferId);
console.log('Status:', transfer.status); // 1 = Pending
```
