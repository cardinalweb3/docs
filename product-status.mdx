This page separates confirmed implementation from pilot assumptions and planned work. Use it to understand exactly what is available today, what requires pilot access, and what remains on the roadmap before you plan an integration.

## Current capability status

| Capability | Status |
| --- | --- |
| Cardinal web experience | Connected MVP |
| Protection API | Controlled pilot |
| SafeSend | Testnet pilot |
| Programmable Escrow | Contract implementation |
| Enterprise Admin Dashboard | Early development |
| External threat intelligence | Planned integration |
| Mainnet deployment | Not yet verified |

**Cardinal web experience** — The product site, application flow, and MetaMask connection are fully implemented and accessible in the connected MVP.

**Protection API** — Authentication, request validation, risk scoring, findings generation, and usage foundations are implemented and available to approved pilot partners.

**SafeSend** — The connected frontend and Protection API flow are implemented. SafeSend currently operates on a testnet flow; production verification remains outstanding.

**Programmable Escrow** — Core lifecycle controls, including release, refund, timeout, and dispute resolution, are implemented at the contract level. Production integration and independent audit remain outstanding.

**Enterprise Admin Dashboard** — The repository and planned module structure exist. This is not a completed product; active development is underway.

**External threat intelligence** — Production provider adapters and owned intelligence datasets are roadmap work. Current scoring uses available internal signals.

**Mainnet deployment** — Requires final configuration, monitoring instrumentation, and a security review before Cardinal operations move to mainnet.

<Note>
  **What "pilot" means** — Pilot access is a 60–90 day controlled programme for approved integration partners. Pilot partners receive direct onboarding support, a sandbox API key, and access to Cardinal's team for technical questions. Capabilities listed as pilot are functional but not yet available for unrestricted production use. To apply, see the [Pilot Onboarding](/resources/pilot-onboarding) page.
</Note>

<Info>
  This page is updated directly from the Cardinal implementation repositories as changes are reviewed and approved. If a capability you need is listed as planned or in early development, contact your Cardinal onboarding contact for roadmap timing.
</Info>
