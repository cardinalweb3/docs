## What to include in a first message

A short note is enough. The more of these you can share, the faster we can get to a useful first call.

| Field | Example |
| --- | --- |
| **Product** | Which Cardinal product interests you most: Protection API, SafeSend, Programmable Escrow, or a combination. |
| **Environment** | Where you would run the pilot: production, staging, testnet, or a controlled cohort. |
| **Use case** | The workflow you want to protect: withdrawals, treasury transfers, RWA issuance, high-value payments, or wallet approvals. |
| **Expected volume** | An approximate transaction volume or notional value for the pilot flow. |
| **Timing** | When you would like to start and any constraints on the pilot window. |

## Suggested email template

```text
Subject: Cardinal pilot enquiry – [your platform name]

Hello Cardinal team,

Product interest:     [Protection API / SafeSend / Programmable Escrow / combination]
Environment:          [production / staging / testnet / controlled cohort]
Use case / workflow:  [e.g. withdrawal protection on exchange XYZ]
Expected volume:      [approx transactions/month or notional value]
Timing:               [target start date and any constraints]

Brief context:
[Two or three lines about your platform, the outcome you want to move and the
stakeholders you would want in the first call.]

Best regards,
[Your name, role, platform]
```

## What happens next

<Steps>
  <Step title="Initial call">
    We understand your workflow, current controls and the outcomes you want to move.
  </Step>
  <Step title="Scoping">
    We agree pilot scope, success measures and commercial terms in writing. A typical pilot runs 60 to 90 days; final scope is agreement-specific.
  </Step>
  <Step title="Kickoff">
    We integrate Cardinal into the target workflow and go live in a controlled way.
  </Step>
</Steps>

<Warning>
  Do not send private keys, seed phrases, API secrets or other credentials in a first message. If we need to exchange anything sensitive later, we will agree a secure channel first.
</Warning>

<Note>
  Cardinal never requests private keys or seed phrases at any stage of a pilot or deployment.
</Note>
